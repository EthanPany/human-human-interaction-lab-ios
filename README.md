# Human Human Interaction Lab: iOS

SwiftUI app for the Cal Hacks 13.0 project. This repo is a submodule of [human-human-interaction-lab](https://github.com/EthanPany/human-human-interaction-lab) and is managed by Xcode's own source control.

Create the Xcode project inside this folder (uncheck "Create Git repository", since this folder already is one). One file per screen: Badge, Worn badge, Profile, Settings, People list, Person detail.

Design: [Figma file](https://www.figma.com/design/fT0XfUlJq0W47Z33XfjnYY/Cal-Hack-13)
